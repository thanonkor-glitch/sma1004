1.1ความรู้เบื้องต้นสมการเชิงอนุพันธ์

สมการเชิงอนุพันธ์เชื่อมฟังก์ชันกับอัตราการเปลี่ยนแปลงของฟังก์ชันนั้น เช่น อัตราเร็วของวัตถุคืออนุพันธ์ของระยะทางเทียบกับเวลา การเรียนเริ่มจากอ่านว่าปริมาณใดเปลี่ยนตามตัวแปรใด แล้วจึงจำแนกและเลือกวิธีแก้สมการ

ตามบท 1 หัวข้อ 1.1 · ลองนึกถึงการเปลี่ยนแปลงหนึ่งอย่าง แล้วระบุปริมาณกับตัวแปรที่ใช้ติดตาม

1.2ความหมายของสมการเชิงอนุพันธ์

หัวข้อ 1.2 / LLO1.1

เริ่มจากสมการในชีท ลองระบุว่าอะไรเปลี่ยนเทียบกับอะไร ก่อนเปิดดูความหมายของแต่ละส่วน

dy/dx = x²

มอง y เป็นฟังก์ชัน y(x) ลองอธิบาย x, y และ dy/dx ด้วยคำของเรา แล้วแตะสัญลักษณ์เพื่อตรวจความคิด

เลือกสัญลักษณ์หลังลองคิด เพื่อดูความหมาย
สมการนี้บอกค่าของ y หรืออัตราการเปลี่ยนแปลงของ y?

สมการบอกว่าอัตราการเปลี่ยนแปลงของ y เทียบกับ x เท่ากับ x² ยังไม่ได้บอกค่า y โดยตรง การอ่านความหมายของอนุพันธ์เป็นจุดเริ่มต้นก่อนศึกษาวิธีหาคำตอบ

LLO1.1 · ความหมาย

อะไรเปลี่ยนตามอะไร?

สมการเชิงอนุพันธ์เชื่อมฟังก์ชันกับอนุพันธ์ของฟังก์ชันนั้น เช่น dy/dx = x² มี x เป็นตัวแปรอิสระ y เป็นตัวแปรตาม และ dy/dx เป็นอัตราการเปลี่ยนแปลงของ y เทียบกับ x

LLO1.2 · ODE / PDE

อนุพันธ์ชนิดไหน?

y(x) กับอนุพันธ์สามัญ เช่น y″ − 4y′ + 4y = 0 เป็น ODE ส่วน u(x,t) กับอนุพันธ์ย่อย เช่น ∂u/∂t = D∂²u/∂x² เป็น PDE

สมการและความหมายจากชีทสัปดาห์ 1 หัวข้อ 1.2

1.3อันดับและดีกรีของสมการเชิงอนุพันธ์

LLO1.2 · อันดับ

หาอนุพันธ์สูงสุด

ใน (y″)³ + y = 0 อนุพันธ์สูงสุดคือ y″ จึงมีอันดับ 2 เลขชี้กำลัง 3 ของ y″ ไม่ใช่อันดับของสมการ

LLO1.2 · ดีกรี

ดูรูปพหุนามของอนุพันธ์

(y″)³ + y = 0 มีดีกรี 3 แต่ y″ + (y′)² = y มีดีกรี 1 เพราะดูที่กำลังของ y″ ซึ่งเป็นอนุพันธ์สูงสุด

ใน y″ + sin(y′) = y มีอนุพันธ์อยู่ในฟังก์ชันไซน์ จึงไม่กำหนดดีกรีในรูปที่ให้มา

อันดับกับดีกรีต่างกัน และดีกรี 1 ไม่รับประกันว่าเป็นเชิงเส้น: y″ + (y′)² = y เป็นตัวอย่างที่ต้องตรวจทุกพจน์

จดความคิด ก่อนเปิดขั้นถัดไป

ตัวอย่างจากหัวข้อ 1.2
y″ − 4y′ + 4y = 0

ลองจำแนกชนิด อันดับ ดีกรี ความเป็นเชิงเส้น และเขียนรูป F = 0 ก่อนเปิดดูวิธีคิด

1

ระบุตัวแปรและชนิดอนุพันธ์

มอง y เป็นฟังก์ชันของ x จึงมี x เป็นตัวแปรอิสระ y เป็นตัวแปรตาม มีอนุพันธ์สามัญ y′ และ y″ จึงเป็น ODE

2

แยกอันดับออกจากดีกรี

อนุพันธ์สูงสุดคือ y″ จึงมีอันดับ 2 สมการเป็นพหุนามของอนุพันธ์ และ y″ มีกำลัง 1 จึงมีดีกรี 1

3

ตรวจความเป็นเชิงเส้นและพจน์บังคับ

y, y′ และ y″ มีกำลังหนึ่ง ไม่คูณกัน และสัมประสิทธิ์เป็นค่าคงที่ จึงเป็นเชิงเส้น เมื่อ g(x) = 0 จึงเป็นเอกพันธ์

4

เขียนเป็นรูปทั่วไป

F(x,y,y′,y″) = y″ − 4y′ + 4y และสมการคือ F(x,y,y′,y″) = 0 นี่เป็นรูปทั่วไปของ ODE อันดับ 2

ขั้น 1 / 4
ลองเปรียบเทียบ: y″ + (y′)² = cos x

อันดับ 2 ดีกรี 1 เหมือนเดิม แต่ไม่เชิงเส้นเพราะ (y′)² เราจึงไม่ใช้การแบ่งเอกพันธ์/ไม่เอกพันธ์ของสมการเชิงเส้นกับข้อนี้

1.4รูปทั่วไปของสมการสามัญอันดับ n

หัวข้อ 1.4 / LLO1.4

F(x, y, y′, …, y(n)) = 0

รูปนี้ครอบคลุมทั้ง ODE เชิงเส้นและไม่เชิงเส้น เลือก n จากอนุพันธ์สูงสุด แล้วจัดพจน์ทั้งหมดให้อยู่ทางเดียวกัน

1

ตัวอย่างในชีท: y″ + sin y = eˣ

n = 2 และ F(x,y,y′,y″) = y″ + sin y − eˣ จึงเขียนสมการเป็น F = 0 ได้ แม้สมการนี้ไม่เชิงเส้น

การเขียน F = 0 ไม่ได้ทำให้สมการเป็นเชิงเส้น ความเป็นเชิงเส้นต้องตรวจโครงสร้างของ y และอนุพันธ์แยกต่างหาก

1.5สมการสามัญอันดับ n ที่เป็นเชิงเส้น

LLO1.3 · เชิงเส้น

ตรวจทุกพจน์ของ y

y และอนุพันธ์ต้องมีกำลังหนึ่ง ไม่คูณกัน และไม่อยู่ในฟังก์ชันอื่น สัมประสิทธิ์ขึ้นกับ x ได้ เช่น xy″ − y cos x = x เป็นเชิงเส้น แต่ y′ + 3y² = sin x ไม่เชิงเส้น

LLO1.3 · เอกพันธ์เชิงเส้น

ตรวจพจน์บังคับ

จัดพจน์ y และอนุพันธ์ไว้ทางซ้าย ถ้าข้างขวา g(x) = 0 เรียกเอกพันธ์ ถ้า g(x) ไม่เป็นฟังก์ชันศูนย์ เรียกไม่เอกพันธ์ ใช้การแบ่งนี้หลังตรวจว่าเป็นเชิงเส้นแล้ว

สำหรับสมการเชิงเส้นอันดับ n ใช้รูป

aₙ(x)y(n) + … + a₁(x)y′ + a₀(x)y = g(x)

สัมประสิทธิ์ขึ้นกับ x เท่านั้น และ aₙ(x) ต้องไม่เป็นศูนย์บนช่วงที่พิจารณา เช่น y‴ + x²y = cos x เขียนเป็น F(x,y,y′,y″,y‴) = y‴ + x²y − cos x = 0

ลองแต่งสมการของเรา · แบบฝึกหัด 1 ข้อ 5

สร้าง ODE เชิงเส้นอันดับสองแบบไม่เอกพันธ์ 1 สมการ พร้อมอธิบายเหตุผล เขียนในช่องนี้หรือในชีทได้

เปิดแนวตรวจ หลังลองเขียนแล้ว
  • มี y″ และสัมประสิทธิ์ของ y″ ไม่เป็นศูนย์บนช่วงที่เลือก
  • y และอนุพันธ์มีกำลังหนึ่ง ไม่คูณกัน สัมประสิทธิ์ขึ้นกับ x เท่านั้น
  • พจน์บังคับ g(x) ไม่เป็นฟังก์ชันศูนย์

ตัวอย่างที่ตรงเงื่อนไข: y″ + 2y′ + y = x โดยมีอันดับ 2 ทุกพจน์เป็นเชิงเส้น และ g(x) = x ไม่เป็นฟังก์ชันศูนย์

มองโครงสร้าง ก่อนเลือกวิธี

เริ่มจาก y′ = f(x,y) แล้วถามว่าจัดรูปด้านขวาได้อย่างไร ลองบอกวิธีที่เหมาะกับสมการแต่ละข้อก่อนอ่านแนวคิด

ตัวอย่าง 2.1-1

y′ = xy

เป็นผลคูณ g(x)h(y) จึงแยกตัวแปรได้ เมื่อหารด้วย h(y) ต้องตรวจกรณี h(y) = 0 แยกไว้ด้วย

ตัวอย่าง 2.1-2

y′ = x²/(1+y²)

แยกได้เช่นกัน: (1+y²)dy = x²dx และ 1+y² > 0 สำหรับ y จริงทุกค่า คำตอบอาจอยู่ในรูปโดยนัย

ตัวอย่าง 2.1-4 / 2.2-1

y′ = 1+y/x

ด้านขวาขึ้นกับ y/x จึงใช้ v = y/x บนช่วง x ≠ 0 เพื่อแปลงเป็นสมการแยกตัวแปรได้

“เอกพันธ์” ในหัวข้อ 2.2 หมายถึง y′ = F(y/x) ส่วน “เอกพันธ์เชิงเส้น” ในบท 1 หมายถึงพจน์บังคับเป็นศูนย์ ต้องดูบริบทของคำนี้ด้วย

หัวข้อ 2.2 / LLO2.1, LLO2.2

ถ้า y′ = F(y/x) ให้แทน y = vx แล้วใช้กฎอนุพันธ์ของผลคูณ จะได้ xv′ = F(v) − v ซึ่งแยกตัวแปรได้ ตรวจ x ≠ 0 และก่อนหารด้วย F(v) − v ให้ตรวจกรณีที่พจน์นี้เป็นศูนย์ด้วย

ตัวอย่าง 2.2-1 · เชื่อม 2.1-4

1

ตัวอย่าง 2.1-3 · เติมการอินทิเกรต

y′ = x cos x / y²

เริ่มให้: y²dy = x cos x dx บนช่วง y ≠ 0 ลองเลือก u, dv สำหรับการอินทิเกรตโดยแยกส่วน แล้วเขียนคำตอบพร้อมตรวจโดเมน

เปิดแนวตรวจตัวอย่าง 2.1-3

ให้ u = x, dv = cos x dx จึงได้ du = dx, v = sin x และ ∫x cos x dx = x sin x + cos x

y³/3 = x sin x + cos x + C หรือ y = ∛[3(x sin x + cos x + C)]

ตรวจ: y²y′ = x cos x จึงได้ y′ = x cos x / y² เมื่อ y ≠ 0 คำตอบต้องอยู่บนช่วงที่ x sin x + cos x + C ≠ 0 ไม่ต่อคำตอบผ่านจุดที่ y = 0 เพราะสมการเดิมไม่ถูกนิยามที่นั่น

ตัวอย่าง 2.2-2 · ตรวจคำตอบก่อนหาร

y′ = (y − x tan(y/x))/x,   y(1) = 0

เริ่มให้: v = y/x, y = vx บนช่วง x > 0 ลองหาสมการของ v แล้วตรวจกรณี tan v = 0 ก่อนแยกโดยการหาร

เปิดแนวตรวจตัวอย่าง 2.2-2

v + xv′ = v − tan v → xv′ = −tan v เงื่อนไขเริ่มต้นให้ v(1) = 0

ก่อนหารด้วย tan v ตรวจคำตอบคงตัว v = kπ ซึ่งให้ tan v = 0 และ y = kπx ค่าเริ่มต้น y(1) = 0 เลือก k = 0 จึงได้ y = 0 บน (0,∞)

แทนกลับ: y′ = 0 และ (0 − x tan 0)/x = 0 สำหรับ x > 0 รวมทั้ง y(1) = 0 ผ่านครบ สมการด้านขวาเรียบใกล้ v = 0 จึงไม่เกิดคำตอบอีกเส้นที่แยกจากเส้นนี้ผ่านจุดเริ่มต้นเดียวกัน

ถ้า tan v ≠ 0 แยกได้ cot v dv = −dx/x แล้วได้ x sin(y/x) = C แต่ต้องคงข้อจำกัดเดิม และคืนกรณีคำตอบคงตัวที่ถูกตัดออกจากการหาร การเขียน x sin(y/x) = 0 อย่างเดียวต้องใช้ค่าเริ่มต้นเลือกสาขา y = 0 ด้วย

จาก y = vx ได้ xv′ = 1/v และแยกเป็น vdv = dx/x ลองอินทิเกรตแล้วแทนกลับด้วย v = y/x พร้อมระบุข้อจำกัดจากตัวหาร

2.3สมการแม่นตรง

LLO2.1, LLO2.3, LLO2.5, LLO2.6 · ชีทสัปดาห์ 3 หน้า 1–5

สมการ M(x,y)dx + N(x,y)dy = 0 เป็นสมการแม่นตรง เมื่อมีฟังก์ชัน f ที่ fₓ = M และ fᵧ = N จึงได้ df = 0 และคำตอบโดยนัย f(x,y) = C เราจะตามหาฟังก์ชันนี้จากอนุพันธ์สองทิศทาง

ตรวจ Mᵧ = Nₓ → หา f = ∫M dx + h(y) → เทียบ fᵧ = N

บนบริเวณสี่เหลี่ยมที่ M, N และอนุพันธ์ย่อยอันดับหนึ่งต่อเนื่อง เงื่อนไข Mᵧ = Nₓ รับประกันว่าหา f ได้ การอินทิเกรตเทียบ x ถือ y คงที่ จึงต้องเติมฟังก์ชัน h(y) แล้วหา h จากการเทียบกับ N

เส้นระดับ f = C เป็นคำตอบโดยนัย ถ้าจะมองเป็น y(x) ใกล้จุดเริ่มต้น ให้ตรวจ fᵧ = N ≠ 0 เพื่อเลือกสาขาที่เหมาะสม
ตัวอย่าง 2.3-1 · เติมวิธีทำ
(2xy + y²)dx + (x² + 2xy)dy = 0
1

ตรวจความแม่นตรง

M = 2xy + y², N = x² + 2xy ดังนั้น Mᵧ = 2x + 2y = Nₓ

2

อินทิเกรตเทียบ x

f = ∫(2xy + y²)dx + h(y) = x²y + xy² + h(y)

3

หาฟังก์ชันที่ยังขาด

fᵧ = x² + 2xy + h′(y) เทียบกับ N ได้ h′(y) = 0 จึงเลือก h = 0 โดยรวมค่าคงตัวไว้ใน C

4

เขียนคำตอบและตรวจกลับ

x²y + xy² = C ตรวจได้ fₓ = 2xy + y² และ fᵧ = x² + 2xy ตามสมการเดิม

ตัวอย่าง 2.3-2 · ปัญหาค่าเริ่มต้น
(3x² + 2y)dx + (2x + cos y)dy = 0,   y(1) = 0

เริ่มทำร่วมกัน: Mᵧ = 2 = Nₓ และ f = x³ + 2xy + h(y) ลองหา h จาก fᵧ = N ก่อนเปิดแนวตรวจ

เปิดแนวตรวจตัวอย่าง 2.3-2

2x + h′(y) = 2x + cos y → h(y) = sin y จึงได้ f = x³ + 2xy + sin y

แทน (x,y) = (1,0) ได้ C = 1 คำตอบคือ x³ + 2xy + sin y = 1

ตรวจ fₓ = 3x² + 2y, fᵧ = 2x + cos y และ f(1,0) = 1 ที่จุดเริ่มต้น N = 3 ≠ 0 จึงมีสาขา y(x) ใกล้ x = 1 ใช้บนช่วงที่สาขานี้ยังมี N ≠ 0 ไม่สรุปว่าใช้ได้บน ℝ ทั้งหมด

ตัวอย่าง 2.3-3 · อ่านโดเมนก่อนทำ
(1/x + y)dx + (x + ln y)dy = 0

สมการเดิมต้องมี x ≠ 0 และ y > 0 ลองหา Mᵧ และ Nₓ ในใจ ก่อนเปิดแนวตรวจ

เปิดแนวตรวจตัวอย่าง 2.3-3

Mᵧ = 1 = Nₓ อินทิเกรตเทียบ x ได้ f = ln|x| + xy + h(y)

fᵧ = x + h′(y) = x + ln y จึงมี h = y ln y − y

คำตอบ: ln|x| + xy + y ln y − y = C ตรวจได้ fₓ = 1/x + y และ fᵧ = x + ln y ใช้ในบริเวณ x > 0, y > 0 หรือ x < 0, y > 0 ตามโดเมนเดิม

ลอง μ(x)

(Mᵧ − Nₓ)/N = g(x)

ถ้าขึ้นกับ x เท่านั้น และ N ≠ 0 ใช้ μ(x) = e∫g(x)dx

ลอง μ(y)

(Nₓ − Mᵧ)/M = h(y)

ถ้าขึ้นกับ y เท่านั้น และ M ≠ 0 ใช้ μ(y) = e∫h(y)dy

ตัวอย่าง 2.4-2 · ให้ μ = x²y
(3y + 4xy²)dx + (2x + 3x²y)dy = 0

ลองคูณทั้ง M และ N ด้วย x²y และตรวจความแม่นตรง สมการที่คูณสมมูลกับสมการเดิมเมื่อ x ≠ 0, y ≠ 0

เปิดแนวตรวจตัวอย่าง 2.4-2
