# SMA1004 Differential Equations

Online lessons for chapters 1–4, with interactive graphs, practice questions, and weekly PDF handouts.

## GitHub Pages

Publish from the `main` branch and `/ (root)` directory in Settings → Pages. Keep `index.html` and `assets/` together.

## Current version

Practice scores and notes are temporary and reset when the page is refreshed or closed. This version does not store grades or send student data to Google Sheets. Both in-class and full handouts are available.
